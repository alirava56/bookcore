# Backup/Restore — مرور امنیتی فاز پانزدهم

ابزار Restore فقط برای مقصد مشخص، دیتابیس خالی و دورریختنی، Login تأییدشدهٔ `session_user` و کلاینت/سرور PG17 طراحی شده است. اجرای مخرب باید از باینری مورداعتماد با مسیر مطلق استفاده کند؛ کلید خصوصی age و SHA-256 Manifest باید از مرز اعتماد مستقل بیایند.

CI بازیابی از Suite عمومی جدا و فقط به‌شکل دستی قابل درخواست است. مسیر تست در GitHub هنگام فقدان پیش‌نیازها باید BLOCKED/FAIL باشد. اجرای موفق `verify()` روی فایل Mock، اثبات Data Restore نیست. ایزولاسیون کامل Writerها در مقصد هنوز وابسته به زیرساخت است و Script به‌تنهایی تضمین نمی‌کند.

**مانع انتشار:** Backup/Restore واقعی، رمزگشایی مستقل، ACL/Ledger و PITR/WAL replay اجرا نشده‌اند.
